# התאמת קורות חיים למשרה — סקיל לקלוד

סקיל של **ניר פרץ, יועץ קריירה**, למועמדים שקיבלו ממנו קורות חיים עם אזורים דינמיים מסומנים בצהוב.

הסקיל מקבל:
1. את קורות החיים שלך בוורד (הקובץ עם הצהוב)
2. קישור למשרה או את תיאור המשרה
3. את שם החברה

שואל אותך שאלה אחת על ערך מוסף שאולי לא מופיע בקורות החיים, ואז מתאים רק את האזורים הצהובים למשרה ומחזיר:
- **קובץ וורד** עם הצהוב, כדי שתראו איפה אפשר לשנות
- **קובץ PDF נקי** בלי צהוב, מוכן לשליחה

הוא לא ממציא כלום: כל מילה מגיעה מקורות החיים שלך או ממה שסיפרת לו.

## התקנה

**ב-Claude Code או באפליקציית Claude למחשב:** פשוט כתבו לקלוד:

> תתקין את הסקיל מהקישור הזה: https://github.com/nirperez/cv-job-tailor

**ב-claude.ai (באתר):**
1. הורידו את הקובץ [cv-job-tailor.zip](https://github.com/nirperez/cv-job-tailor/raw/main/cv-job-tailor.zip)
2. ב-claude.ai היכנסו ל-Settings ← Capabilities ← Skills
3. לחצו Upload skill ובחרו את הקובץ

## שימוש

אחרי ההתקנה כתבו לקלוד למשל: "תתאים לי את הקורות חיים למשרה הזו" וצרפו את קובץ הוורד, את הקישור למשרה ואת שם החברה.

לפני כל שליחה: קראו את קורות החיים פעם אחת מההתחלה עד הסוף. אתם אלה שיתראיינו עליהם.
